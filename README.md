# debugit-attack-test-no-ruleset

A test repository for the security tests of GitHub Runner Monitor: https://github.com/amir-bialek/Github-Runner-Monitor

GitHub Runner Monitor's Debug it feature opens fix pull requests only in repositories whose main branch is protected by a ruleset.
This repository has no ruleset on purpose.
The security tests check that Debug it refuses to open a pull request here and never writes anything to it.

It holds no code and is not meant to be used.
